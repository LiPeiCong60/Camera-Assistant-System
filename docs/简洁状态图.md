# 简洁状态图

本文提供适合横向排版的简洁版状态图。
目标是：

- 先有一张总体状态图
- 再拆关键模块状态
- 状态数量少，便于 PPT / 论文横向展示

---

## 1. 总体状态图

```mermaid
stateDiagram-v2
  [*] --> 系统入口

  系统入口 --> 手机独立拍摄域
  系统入口 --> 设备联动域
  系统入口 --> 历史缓存域

  state 手机独立拍摄域 {
    [*] --> 就绪
    就绪 --> 拍照中
    拍照中 --> 写历史中
    写历史中 --> 就绪
    写历史中 --> 写历史失败
    就绪 --> AI分析中
    AI分析中 --> AI结果可见
    AI分析中 --> AI失败
  }

  state 设备联动域 {
    [*] --> 会话未打开
    会话未打开 --> 会话已打开
    会话已打开 --> 推流中
    推流中 --> 预览中
    预览中 --> 设备功能运行中
    设备功能运行中 --> 预览中
    会话已打开 --> 会话关闭中
    会话关闭中 --> 会话未打开
  }

  state 历史缓存域 {
    [*] --> 在线加载中
    在线加载中 --> 在线数据可见
    在线加载中 --> 缓存回退
    缓存回退 --> 缓存数据可见
    缓存回退 --> 加载失败
  }
```
