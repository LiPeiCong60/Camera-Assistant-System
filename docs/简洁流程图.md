# 简洁流程图

本文提供适合横向放置的简洁版流程图。
结构采用“总图 + 模块图”，尽量减少节点数量，只保留最关键路径。

---

## 1. 总体流程图

```mermaid
flowchart LR
  A[用户进入系统] --> B{选择功能}

  B --> C[手机独立拍摄]
  B --> D[设备联动]

  C --> C1[获取模板]
  C1 --> C2[拍照]
  C2 --> C3[创建 session]
  C3 --> C4[上传图片]
  C4 --> C5[写入历史]
  C5 --> C6{是否发起后端 AI}
  C6 -->|是| C7[调用 AI 分析并返回结果]
  C6 -->|否| C8[直接结束]

  D --> D1[打开设备会话]
  D1 --> D2[启动手机推流]
  D2 --> D3[树莓派检测 / 构图 / 预览回传]
  D3 --> D4{选择设备功能}
  D4 --> D5[手动控制 / 模式切换]
  D4 --> D6[自动找角度]
  D4 --> D7[背景锁机位]
  D4 --> D8[抓拍]
```

---

## 2. 手机独立拍摄流程图

```mermaid
flowchart LR
  A[进入拍摄页] --> B[加载模板]
  B --> C[打开手机相机]
  C --> D[用户拍照]
  D --> E[创建 session]
  E --> F[上传图片]
  F --> G[创建 capture 历史]
  G --> H{是否继续 AI 分析}
  H -->|是| I[调用后端 AI]
  H -->|否| J[结束]
  I --> K[展示 AI 结果]
```

---

## 3. 后端 AI 分析流程图

```mermaid
flowchart LR
  A[用户发起 AI 分析] --> B[校验 capture / session]
  B --> C{校验通过?}
  C -->|否| D[返回失败]
  C -->|是| E[解析可用 Provider]
  E --> F{Provider 可用?}
  F -->|否| G[创建 failed ai_task]
  F -->|是| H[创建 pending ai_task]
  H --> I[调用 AI Provider]
  I --> J{调用成功?}
  J -->|否| K[更新为 failed]
  J -->|是| L[更新为 succeeded]
```

## 4. 设备联动主流程图

```mermaid
flowchart LR
  A[进入设备联动页] --> B[加载模板与连接配置]
  B --> C[打开设备会话]
  C --> D[启动手机推流]
  D --> E[树莓派接收实时帧]
  E --> F[检测 / 构图 / overlay]
  F --> G{是否需要控制云台?}
  G -->|是| H[输出 pan / tilt 控制]
  G -->|否| I[保持当前姿态]
  H --> J[回传预览]
  I --> J
  J --> K[手机显示 HUD 与状态]
```

## 5. 自动找角度流程图

```mermaid
flowchart LR
  A[启动自动找角度] --> B[生成候选角度]
  B --> C[云台逐个扫描]
  C --> D[保存候选帧]
  D --> E{是否扫描完成?}
  E -->|否| C
  E -->|是| F[设备端 AI 分析候选图]

  G --> H{是否应用建议?}
  H -->|是| I[驱动云台转到建议位置]
  H -->|否| J[仅展示建议]
```

## 7. 手势抓拍流程图

```mermaid
flowchart LR
  A[实时推流中] --> B[树莓派持续做手部检测]
  B --> C{识别到有效手势?}
  C -->|否| B
  C -->|是| D[启动 3 秒倒计时]
  D --> E{倒计时期间手势仍有效?}
  E -->|否| B
  E -->|是| F{倒计时结束?}
  F -->|否| D
  F -->|是| G[执行抓拍]
  G --> H[保存到本地 captures]
  H --> I[返回抓拍结果]
```

## 8. 模板流程图

```mermaid
flowchart LR
  A[进入模板功能] --> B{模板来源}
  B -->|后端模板| C[请求 mobile/templates]
  B -->|设备模板| D[请求 device/templates]
  C --> E[展示用户模板]
  D --> F[展示树莓派模板]
  E --> G{是否新增模板?}
  F --> H{是否上传设备模板?}
  G -->|是| I[上传照片并生成模板]
  H -->|是| J[上传到树莓派并生成本地模板]
```

## 9. 历史与缓存流程图

```mermaid
flowchart LR
```
