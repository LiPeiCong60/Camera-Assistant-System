# 云影随行接口契约

> 更新时间：2026-07-10。具体请求与响应模型以 FastAPI 启动后的 `/docs` 为准。

## 1. 服务边界

| 服务 | 默认地址 | 职责 |
| --- | --- | --- |
| 业务后端 | `http://127.0.0.1:8000` | 用户、套餐、模板、媒体、AI 任务与 Provider |
| 设备运行时 | `http://127.0.0.1:8001` | 手机帧输入、检测、预览、云台与模板控制 |
| 管理后台 | `http://127.0.0.1:5173` | 调用业务后端 `/api/admin/*` |
| Flutter 手机端 | 真机或模拟器 | 调用业务后端与设备运行时两个地址 |

## 2. 业务后端响应格式

普通 JSON 接口使用统一包装：

```json
{
  "success": true,
  "message": "ok",
  "data": {}
}
```

列表数据的 `data` 至少包含 `items`。需要登录的手机端和管理端接口使用：

```http
Authorization: Bearer <token>
```

文件上传使用 `multipart/form-data`；上传后的文件由 `/uploads/*` 提供静态访问。

## 3. 业务后端核心接口

### 手机端 `/api/mobile`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/auth/login` | 手机号和密码登录 |
| `POST` | `/auth/register` | 注册并返回登录态 |
| `GET` | `/me` | 当前用户 |
| `GET` | `/plans` | 可用套餐 |
| `GET` | `/subscription` | 当前订阅 |
| `GET/POST/DELETE` | `/templates` | 用户模板查询、创建与删除 |
| `POST` | `/sessions` | 创建拍摄会话 |
| `POST` | `/captures/file` | 上传照片或视频文件 |
| `POST` | `/captures/upload` | 写入媒体记录 |
| `POST` | `/ai/analyze-photo` | 单图构图分析 |
| `POST` | `/ai/analyze-background` | 背景和站位分析 |
| `POST` | `/ai/batch-pick` | 2 至 9 张连拍选优 |
| `POST` | `/ai/analyze-scan` | 1 至 12 张多角度候选图分析 |
| `GET` | `/ai/tasks/{task_id}` | 查询 AI 任务 |
| `GET` | `/history/sessions` | 拍摄会话历史 |
| `GET` | `/history/captures` | 媒体历史 |

### 管理端 `/api/admin`

管理端提供登录、用户、套餐、推荐模板、设备、媒体、AI 任务、统计和 AI Provider 配置接口。除登录外应使用管理员 Token。

## 5. 跨端枚举

### `capture_sessions.mode`

`mobile_only`、`gimbal_manual`、`gimbal_follow`、`gimbal_template`、`ai_auto_angle`、`ai_background`。

后端兼容旧值：`device_link -> gimbal_manual`、`MANUAL -> gimbal_manual`、`AUTO_TRACK -> gimbal_follow`、`SMART_COMPOSE -> gimbal_template`。

### `captures.capture_type`

`single`、`burst`、`best`、`background`、`template`、`recording`。旧值 `photo` 和 `device_link` 归一化为 `single`。

### `ai_tasks.task_type`

`analyze_photo`、`analyze_background`、`batch_pick`、`auto_angle`、`template_match`、`video_analysis`。

## 6. 视觉坐标

跨端坐标统一使用 `0..1` 归一化值。AI 推荐人物框使用对象格式：

```json
{
  "x": 0.31,
  "y": 0.14,
  "w": 0.36,
  "h": 0.70,
  "label": "recommended_person_position"
}
```

后端仍兼容旧数组 `[x, y, w, h]`，新代码应写对象格式。模板关键点字段和投影规则见 [数据字典](数据字典.md)。

## 7. 配置约定

- 手机端业务地址应以 `/api` 结尾，设备地址不追加业务后端前缀。
- Android 模拟器访问宿主机可用 `10.0.2.2`；真机使用电脑或树莓派局域网 IP。
- AI Provider Key 只应由业务后端保存与调用。
- 实际接口参数、状态码和 schema 以两个 FastAPI 服务的 Swagger 文档为最终依据。
