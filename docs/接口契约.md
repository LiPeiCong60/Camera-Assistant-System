# 接口契约

本文列出当前代码中的主要 HTTP/WebSocket 接口和跨端数据约定。

## 通用约定

业务后端和设备运行时大多数 HTTP 接口返回 JSON envelope：

```json
{
  "success": true,
  "message": "ok",
  "data": {}
}
```

地址约定：

- 业务后端：`http://host:8000/api`
- 设备运行时：`http://host:8001`
- 管理后台：`http://host:5173`

真机联调必须使用局域网 IP，不要使用手机自身的 `127.0.0.1`。

## 核心数据约定

### 坐标

所有跨端视觉坐标都使用 `0..1` 归一化坐标。手机端根据预览尺寸、镜头方向和画面裁剪方式转换为屏幕坐标。

### `target_box_norm`

推荐对象格式：

```json
{
  "x": 0.31,
  "y": 0.14,
  "w": 0.36,
  "h": 0.70,
  "label": "recommended_person_position"
}
```

后端兼容旧数组 `[x, y, w, h]`，但新接口应使用对象。

### `template_data`

推荐结构：

```json
{
  "bbox": {"x": 0.2, "y": 0.1, "w": 0.6, "h": 0.8},
  "head_box": {"x": 0.34, "y": 0.08, "w": 0.28, "h": 0.22},
  "points": {"11": {"x": 0.42, "y": 0.35}, "12": {"x": 0.58, "y": 0.35}},
  "segments": [{"from": "11", "to": "12"}],
  "shoulder_center": {"x": 0.5, "y": 0.35},
  "face_center": {"x": 0.5, "y": 0.18},
  "source_image_url": "/uploads/templates/example.jpg"
}
```

## 手机端到业务后端

Base URL：`/api/mobile`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/auth/login` | 手机登录 |
| `POST` | `/auth/register` | 手机注册 |
| `GET` | `/me` | 当前用户信息 |
| `GET` | `/plans` | 套餐列表 |
| `GET` | `/subscription` | 当前用户订阅 |
| `POST` | `/templates` | 创建用户模板 |
| `GET` | `/templates` | 用户模板列表 |
| `DELETE` | `/templates/{template_id}` | 删除用户模板 |
| `POST` | `/sessions` | 创建拍摄会话 |
| `POST` | `/captures/upload` | 创建媒体记录 |
| `POST` | `/captures/file` | 上传照片或视频文件 |
| `POST` | `/ai/analyze-photo` | 创建照片分析任务 |
| `POST` | `/ai/analyze-background` | 创建背景分析任务 |
| `POST` | `/ai/batch-pick` | 连拍选优 |
| `POST` | `/ai/analyze-scan` | 多角度候选图统一分析 |
| `GET` | `/ai/tasks/{task_id}` | 查询 AI 任务 |
| `GET` | `/history/sessions` | 历史拍摄会话 |
| `GET` | `/history/captures` | 历史媒体记录 |

### 多角度扫描请求

`POST /api/mobile/ai/analyze-scan` 使用 multipart：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `files` | file[] | 1 到 12 张候选图 |
| `task_type` | string | `auto_angle` 或 `analyze_background` |
| `candidates_json` | string | 候选角度元数据 JSON |
| `metadata_json` | string | 入口、设备、模板、扫描设置等上下文 |

候选元数据示例：

```json
[
  {"candidate_index": 1, "pan_offset": -10.0, "tilt_offset": 0.0},
  {"candidate_index": 2, "pan_offset": 0.0, "tilt_offset": 0.0},
  {"candidate_index": 3, "pan_offset": 10.0, "tilt_offset": 0.0}
]
```

## 手机端到设备运行时

Base URL：`http://host:8001`

### 状态和配置

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/device/health` | 运行时健康检查 |
| `GET` | `/api/device/status` | 会话、云台、检测、手势、模板、AI 锁定状态 |
| `PATCH` | `/api/device/config` | 更新 overlay、检测、手势配置 |
| `GET` | `/api/device/preview.jpg` | 调试用单张预览 |
| `WS` | `/api/device/preview-ws` | 调试用 JPEG 预览流 |

### 会话

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/device/session/open` | 打开设备会话 |
| `POST` | `/api/device/session/close` | 关闭设备会话 |

手机推流会话示例：

```json
{
  "session_code": "mobile-session",
  "stream_url": "mobile_push",
  "preview_source": "phone_camera",
  "mirror_view": false,
  "start_mode": "MANUAL"
}
```

### 视频流

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/device/stream/start` | 切换视频源 |
| `WS` | `/api/device/stream/mobile-ws` | 手机帧上行主链路 |
| `POST` | `/api/device/stream/frame` | 调试用单帧上传 |
| `POST` | `/api/device/webrtc/offer` | WebRTC signaling，保留实验链路 |

### 云台和模式

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/device/control/manual-move` | 手动移动或停止 |
| `POST` | `/api/device/control/mode` | 设置运行模式 |
| `POST` | `/api/device/control/home` | 回中 |
| `POST` | `/api/device/control/follow-mode` | 设置跟随目标 |
| `POST` | `/api/device/control/sensitivity` | 设置跟随灵敏度 |
| `POST` | `/api/device/control/track-target` | 手机端识别后直接发送归一化目标点 |

`track-target` 推荐格式：

```json
{
  "target": {"x": 0.52, "y": 0.38},
  "frame": {"width": 1080, "height": 1920},
  "mode": "shoulders",
  "template_target": {"x": 0.50, "y": 0.35},
  "precise": true
}
```

### 模板

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/device/templates` | 设备端模板列表 |
| `GET` | `/api/device/templates/{template_id}/image` | 模板图片 |
| `POST` | `/api/device/templates/import` | 从后端模板导入 |
| `POST` | `/api/device/templates/upload` | 上传设备端模板 |
| `DELETE` | `/api/device/templates/{template_id}` | 删除设备端模板 |
| `POST` | `/api/device/templates/clear` | 清空当前模板 |
| `POST` | `/api/device/templates/select` | 选择模板，可直接传 `template_data` |

当前产品应优先使用后端/手机模板列表，设备端模板接口保留用于兼容和调试。

### 抓拍

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/device/capture/trigger` | 触发设备端本地抓拍/兼容抓拍事件 |
| `POST` | `/api/device/capture/mobile-ack` | 手机确认已处理设备抓拍 |
| `GET` | `/api/device/capture/list` | 本地抓拍文件列表 |
| `GET` | `/api/device/capture/file` | 下载本地抓拍文件 |

设备联动最终拍照/录像主流程使用手机相机保存到相册，不要求在树莓派保存文件。

### 设备端 AI 兼容接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/device/ai/analyze-upload` | 设备端本地分析兼容接口 |
| `POST` | `/api/device/ai/angle-search/start` | 旧设备端角度搜索 |
| `POST` | `/api/device/ai/background-lock/start` | 旧设备端背景锁定 |
| `POST` | `/api/device/ai/background-lock/unlock` | 解除本地锁定 |
| `GET` | `/api/device/ai/status` | 本地 AI 状态 |
| `POST` | `/api/device/ai/apply-angle` | 应用角度建议 |
| `POST` | `/api/device/ai/apply-lock` | 应用背景锁定建议 |

生产主流程建议使用手机主控 + 后端 AI：`/api/mobile/ai/analyze-scan`。
