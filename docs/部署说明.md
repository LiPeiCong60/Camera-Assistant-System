# 部署说明

本文给出本机开发、Android 真机联调、树莓派运行和 APK 构建方式。

## 端口

| 服务 | 默认地址 | 说明 |
| --- | --- | --- |
| backend | `http://0.0.0.0:8000/api` | 业务后端 |
| device_runtime | `http://0.0.0.0:8001` | 树莓派/设备运行时 |
| admin_web | `http://127.0.0.1:5173` | 管理后台开发服务 |

真机访问电脑服务时必须使用电脑局域网 IP；真机访问树莓派时使用树莓派局域网 IP。

## 1. 准备 PostgreSQL

创建数据库：

```powershell
createdb camera_assistant
```

已有数据库时可直接运行后端初始化脚本，它会创建表并做兼容升级。

## 2. 启动 backend

推荐从仓库根目录启动：

```powershell
cd <repo-root>
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt

$env:DATABASE_URL="postgresql+psycopg://postgres:<db_password>@127.0.0.1:5432/camera_assistant"
$env:BACKEND_AUTH_SECRET="<random-secret>"

python backend\init_db.py
python -m uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```

检查：

```powershell
curl http://127.0.0.1:8000/api/health
```

## 3. 启动 admin_web

```powershell
cd <repo-root>\admin_web
npm install
$env:VITE_API_BASE_URL="http://127.0.0.1:8000/api"
npm run dev
```

浏览器打开：

```text
http://127.0.0.1:5173
```

## 4. Windows 本机启动 device_runtime

无真实舵机时使用 mock：

```powershell
cd <repo-root>
.\.venv\Scripts\Activate.ps1
pip install -r device_runtime\requirements.txt

$env:DEVICE_SERVO_DRIVER="mock"
python -m uvicorn device_runtime.api.app:app --reload --host 0.0.0.0 --port 8001
```

检查：

```powershell
curl http://127.0.0.1:8001/api/device/health
```

## 5. 树莓派启动 device_runtime

如果已经把最新文件传到树莓派：

```bash
cd ~/camera_assistant_pi
python3 -m venv .venv
source .venv/bin/activate
pip install -r device_runtime/requirements.txt

export DEVICE_RPI_PROFILE=performance
export DEVICE_SERVO_DRIVER=ttl_bus
export DEVICE_TTL_SERIAL_PORT=/dev/ttyUSB0
export DEVICE_PAN_SERVO_ID=0
export DEVICE_TILT_SERVO_ID=1

python -m uvicorn device_runtime.api.app:app --host 0.0.0.0 --port 8001
```

如果串口不是 `/dev/ttyUSB0`，先查：

```bash
ls /dev/ttyUSB* /dev/ttyACM*
```

树莓派端不需要配置生产 AI Key。生产 AI 分析由手机上传到 `backend`，再由后端调用 Provider。

## 6. 启动 mobile_client

Android 模拟器访问电脑服务：

```powershell
cd <repo-root>\mobile_client
flutter pub get
flutter run `
  --dart-define=API_BASE_URL=http://10.0.2.2:8000/api `
  --dart-define=DEVICE_API_BASE_URL=http://10.0.2.2:8001
```

Android 真机联调：

```powershell
flutter run `
  --dart-define=API_BASE_URL=http://192.168.1.20:8000/api `
  --dart-define=DEVICE_API_BASE_URL=http://192.168.1.30:8001
```

其中：

- `API_BASE_URL` 填电脑或服务器的后端地址。
- `DEVICE_API_BASE_URL` 填树莓派设备运行时地址。

也可以在 App 设置页中修改这两个地址。

## 7. 构建 APK

```powershell
cd <repo-root>\mobile_client
flutter clean
flutter pub get
flutter build apk --release `
  --dart-define=API_BASE_URL=http://192.168.1.20:8000/api `
  --dart-define=DEVICE_API_BASE_URL=http://192.168.1.30:8001
```

输出：

```text
mobile_client/build/app/outputs/flutter-apk/app-release.apk
```

## 8. AI Provider 配置

生产 AI 只在管理后台配置：

1. 启动 backend 和 admin_web。
2. 登录管理后台。
3. 打开 AI Provider 配置。
4. 新增或启用 OpenAI-compatible Provider。
5. 填写 Provider base URL、模型名和 API Key。
6. 在套餐 `feature_flags` 中绑定默认 Provider 或可用 Provider。

手机端和树莓派端不需要保存 AI Key。

## 9. 重启规则

| 修改内容 | 是否需要重启 |
| --- | --- |
| `device_runtime` Python 代码 | 需要重启树莓派 `uvicorn` |
| 树莓派环境变量、串口、舵机 ID | 需要重启树莓派 `uvicorn` |
| Flutter Dart 代码 | 需要重新运行或重装 App |
| Android 权限、Gradle、依赖 | 需要重新构建 APK |
| 后端 Python 代码 | 开发 reload 可自动加载；生产需要重启 |
| 管理后台代码 | 开发 Vite 自动刷新；生产需要重新构建 |

## 10. 安全项

- 不要把 `.env`、API Key、数据库密码、用户照片、视频和日志提交到 Git。
- 后端生产环境必须使用随机 `BACKEND_AUTH_SECRET`。
- 管理后台生产部署应配置 HTTPS、反向代理和更严格 CORS。
- 真机联调使用局域网 HTTP 时，确认网络环境可信。
