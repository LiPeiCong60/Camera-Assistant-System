# 云影随行数据字典

> 更新时间：2026-07-10。全新数据库结构见 `database/schema.sql`，已有数据库升级优先运行 `python backend/init_db.py`。

## 1. 关系概览

```text
users
├── user_subscriptions ── plans
├── devices
├── templates
└── capture_sessions
    ├── captures
    └── ai_tasks

ai_provider_configs  # 独立的 AI Provider 配置
```

## 2. 核心表

### `users`

用户与管理员账号。核心字段：`user_code`、`phone`、`email`、`password_hash`、`display_name`、`role`、`status`、`last_login_at`。

- `role`: `user | admin`
- `status`: `active | inactive | disabled`

### `plans`

套餐定义。核心字段：`plan_code`、`name`、`price_cents`、`currency`、`billing_cycle_days`、`capture_quota`、`ai_task_quota`、`feature_flags`、`status`。

`feature_flags` 为 JSONB，可保存 Provider 选择和其他套餐能力开关。

### `user_subscriptions`

用户套餐关系。核心字段：`user_id`、`plan_id`、`status`、`started_at`、`expires_at`、`auto_renew`、`quota_snapshot`。

### `devices`

设备登记信息。核心字段：`user_id`、`device_code`、`device_name`、`device_type`、`serial_number`、`local_ip`、`control_base_url`、`firmware_version`、`status`、`is_online`、`last_seen_at`。

当前 `device_type` 只允许 `raspberry_pi`。

### `templates`

用户模板与推荐模板。核心字段：`user_id`、`name`、`template_type`、`source_image_url`、`preview_image_url`、`template_data`、`is_recommended_default`、`recommended_sort_order`、`status`。

- `template_type`: `pose | background | composition`
- `status`: `active | archived | deleted`

`template_data` 主要字段：

| 字段 | 格式 | 说明 |
| --- | --- | --- |
| `bbox_norm` | `[x, y, w, h]` | 人物框 |
| `head_bbox_norm` | `[x, y, w, h]` | 头部框 |
| `pose_points_image` | 点数组/对象 | 整张图归一化关键点 |
| `pose_points_bbox` | 点数组/对象 | 人物框内部归一化关键点 |
| `pose_points` | 点数组/对象 | 姿态相似度计算用身体坐标 |
| `shoulder_anchor_norm_x/y` | 数值 | 肩部锚点 |
| `face_anchor_norm_x/y` | 数值 | 面部锚点 |
| `head_anchor_norm_x/y` | 数值 | 头部锚点 |

### `capture_sessions`

一次拍摄或设备联动会话。核心字段：`session_code`、`user_id`、`device_id`、`template_id`、`mode`、`status`、`started_at`、`ended_at`、`metadata`。

- `mode`: `mobile_only | gimbal_manual | gimbal_follow | gimbal_template | ai_auto_angle | ai_background`
- `status`: `opened | closed | cancelled`

### `captures`

手机上传的照片、视频及其业务记录。核心字段：`session_id`、`user_id`、`capture_type`、`file_url`、`thumbnail_url`、`width`、`height`、`storage_provider`、`is_ai_selected`、`score`、`metadata`。

- `capture_type`: `single | burst | best | background | template | recording`
- `metadata.media_type`: `photo | video`
- `metadata.duration_ms`: 视频时长，非负整数
- `metadata.local_album_saved`: 是否已保存到手机相册

### `ai_tasks`

视觉模型任务与结构化结果。核心字段：`task_code`、`user_id`、`session_id`、`capture_id`、`device_id`、`task_type`、`status`、`provider_name`、`request_payload`、`response_payload`、`result_summary`、`result_score`、推荐角度、`target_box_norm`、`error_message`、`finished_at`。

- `task_type`: `analyze_photo | analyze_background | batch_pick | auto_angle | template_match | video_analysis`
- `status`: `pending | running | succeeded | failed | cancelled`
- `target_box_norm`: `{x, y, w, h, label}`，所有几何值在 `0..1` 范围内

### `ai_provider_configs`

模型服务配置。核心字段：`provider_code`、`vendor_name`、`provider_format`、`display_name`、`api_base_url`、`api_key`、`model_name`、`enabled`、`is_default`、`notes`、`extra_config`。

当前调用实现以 `openai_compatible` 为主。API 返回时应使用脱敏字段展示 Key，不得返回明文。

## 3. 删除规则

- 用户删除：级联删除其订阅、设备、模板、拍摄会话、媒体和 AI 任务。
- 套餐被订阅引用时：禁止直接删除。
- 设备或模板删除：拍摄会话中的对应外键置空。
- 拍摄会话删除：级联删除媒体；AI 任务的会话外键置空。
- 媒体删除：AI 任务的媒体外键置空。

## 4. 时间与扩展字段

- 业务时间统一使用 PostgreSQL `TIMESTAMPTZ`。
- 主要表均包含 `created_at` 与 `updated_at`，数据库触发器负责刷新 `updated_at`。
- `metadata`、`feature_flags`、`quota_snapshot`、请求/响应和 Provider 扩展配置使用 JSONB，新增字段时应保持向后兼容。

## 5. 初始化与升级

```bash
export DATABASE_URL="postgresql+psycopg://postgres:password@127.0.0.1:5432/camera_assistant"
python backend/init_db.py
```

`backend/init_db.py` 会执行 ORM 建表和旧库兼容补丁。`database/schema.sql` 更适合查看全新库结构，不替代后续正式迁移工具。
