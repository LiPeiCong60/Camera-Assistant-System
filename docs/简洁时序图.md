# 简洁时序图

本文提供适合横向排版的简洁版时序图。
目标是：

- 先有一张总体图
- 再按核心模块拆分
- 节点少、逻辑清楚、适合 PPT / 论文横向放置

---

## 1. 总体时序图

```mermaid
sequenceDiagram
  actor 用户
  participant 手机App
  participant 业务后端
  participant 树莓派运行时
  participant AI服务
  participant 本地存储

  用户->>手机App: 进入系统并选择功能
  alt 手机独立拍摄
    手机App->>业务后端: 获取模板 / 历史
    用户->>手机App: 拍照
    手机App->>业务后端: 创建 session / 上传图片 / 写入历史
    opt 发起后端 AI
      手机App->>业务后端: 请求 AI 分析
      业务后端->>AI服务: 调用分析
      AI服务-->>业务后端: 返回结果
      业务后端-->>手机App: 返回 AI 结果
    end
  else 设备联动
    手机App->>树莓派运行时: 打开设备会话
    手机App->>树莓派运行时: 推送手机实时画面
    树莓派运行时-->>手机App: 回传预览与状态
    opt 自动找角度 / 背景锁机位
      树莓派运行时->>AI服务: 设备端 AI 分析
      AI服务-->>树莓派运行时: 返回建议
      树莓派运行时-->>手机App: 返回建议结果
    end
    opt 抓拍
      树莓派运行时->>本地存储: 保存本地抓拍
      本地存储-->>树莓派运行时: capture_path
      树莓派运行时-->>手机App: 返回抓拍结果
    end
  end
```

## 2. 手机独立拍摄时序图

```mermaid
sequenceDiagram
  actor 用户
  participant 手机App
  participant 手机相机
  participant 业务后端
  participant 数据库

  用户->>手机App: 打开拍摄页
  手机App->>业务后端: 获取模板
  业务后端->>数据库: 查询模板
  数据库-->>业务后端: 返回模板
  业务后端-->>手机App: 返回模板

  用户->>手机App: 点击拍照
  手机App->>手机相机: takePicture()
  手机相机-->>手机App: 返回照片

  手机App->>业务后端: 创建 session
  业务后端->>数据库: 写 capture_session
  业务后端-->>手机App: 返回 session

  手机App->>业务后端: 上传图片并创建 capture
  业务后端->>数据库: 写 capture
  业务后端-->>手机App: 返回历史记录
```

## 8. 历史与缓存回退时序图

```mermaid
sequenceDiagram
  actor 用户
  participant 手机App
  participant 业务后端
  participant 本地缓存

  用户->>手机App: 打开历史页
  手机App->>业务后端: 请求 sessions / captures
  alt 在线成功
    业务后端-->>手机App: 返回最新历史
    手机App->>本地缓存: 更新缓存
    手机App-->>用户: 展示最新历史
  else 在线失败
    手机App->>本地缓存: 读取缓存
    本地缓存-->>手机App: 返回缓存数据
    手机App-->>用户: 展示缓存历史
  end
```
